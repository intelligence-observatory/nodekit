1Introduction

Behavioral tasks are a central tool for evaluating human, and now artificial, intelligence. Cognitive science, neuroscience, psychology, and other fields offer rich experimental traditions, but each specifies its tasks in its own languages and tools.

We propose nkl as a common language that unifies many of those tasks, and allows them to be easily deployed to any agent, human or model, without modification.

4Deploy

Deploy a single nkl task, without modification, using one command for each setting:

In the lab
nkl play task.py
On Prolific
nkl bundle task.py
To AI agents
nkl sim task.py
